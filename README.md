# صيّاد الأسعار 🎯 — Price Hunter Egypt

موقع لمقارنة أسعار المنتجات في مواقع التسوق المصرية (جوميا، نون، أمازون مصر).
اكتب اسم المنتج → الموقع يبحث في المتاجر → يطلعلك تقرير مرتب بالأسعار مع أرخص عرض.

## التشغيل محليًا

```bash
pip install -r requirements.txt
python app.py
# افتح http://localhost:8000
```

## 🚀 النشر المجاني على Render (الطريقة الموصى بها)

1. ارفع مجلد المشروع على **GitHub** (repo جديد).
2. افتح حساب مجاني على [render.com](https://render.com) (بدون بطاقة ائتمان).
3. اختر **New → Web Service** واربط الريبو.
4. الإعدادات:
   - **Build Command:** `pip install -r requirements.txt`
   - **Start Command:** `uvicorn app:app --host 0.0.0.0 --port $PORT`
   - **Plan:** Free
5. اضغط Deploy → هتحصل على رابط عام `https://your-app.onrender.com`

> ملاحظة: الخطة المجانية بتنام بعد 15 دقيقة بدون زيارات، وأول زيارة بعد النوم بتاخد ~دقيقة (Cold start) — ده طبيعي في المجاني.

## المكونات

| الملف | الوظيفة |
|---|---|
| `app.py` | سيرفر FastAPI — نقطة البحث `/api/search?q=...` |
| `scrapers/jumia.py` | سكرابر جوميا (تحليل صفحة البحث HTML) |
| `scrapers/noon.py` | سكرابر نون (تحليل بيانات __NEXT_DATA__) |
| `scrapers/amazon.py` | سكرابر أمازون مصر (تحليل بطاقات النتائج) |
| `demo_data.py` | بيانات تجريبية من رصد السوق المصري (أكتوبر 2026) |
| `static/index.html` | الواجهة (عربي RTL) |

## ⚠️ ملاحظة مهمة عن الحظر

مواقع جوميا ونون وأمازون بتحظر الطلبات الآلية (Cloudflare/Anti-bot) من السيرفرات السحابية.
عشان السكرابينج الحي يشتغل فعليًا:

1. **انشر المشروع على سيرفر VPS عادي** (يفضل IP مصري/أوروبي) — غالبًا جوميا هتشتغل مباشرة.
2. **لنون وأمازون**: استخدم بروكسي سكني (Residential Proxy) أو شغّل Playwright بمتصفح حقيقي:
   ```bash
   pip install playwright && playwright install chromium
   ```
3. ضع مهلة بين الطلبات ولا تكثر منها (Rate limiting) احترامًا للمواقع.

## وضع العرض التجريبي

لما المتاجر ترفض الاتصال، الموقع يعرض تلقائيًا بيانات تجريبية واقعية
(من رصد أسعار أكتوبر 2026) مع شريط تنبيه واضح — عشان تجرب التجربة كاملة.
